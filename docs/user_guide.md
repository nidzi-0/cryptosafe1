# CryptoSafe Manager — руководство пользователя

## 1. Назначение программы

CryptoSafe Manager — это локальный менеджер паролей, предназначенный для безопасного хранения учётных данных пользователя.

Приложение позволяет:

* создать защищённое хранилище;
* хранить логины, пароли, ссылки, заметки и теги;
* шифровать записи перед сохранением в базу данных;
* копировать данные через защищённый буфер обмена;
* вести журнал событий безопасности;
* импортировать и экспортировать данные;
* использовать panic mode для экстренной блокировки;
* автоматически блокировать хранилище при неактивности.

Основная цель приложения — обеспечить локальное хранение паролей без передачи данных на внешние серверы.

---

## 2. Установка и запуск

### 2.1. Установка зависимостей

Перед запуском необходимо установить зависимости проекта.

Команды выполняются из корневой папки проекта:

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

### 2.2. Запуск из исходного кода

Основной способ запуска:

```powershell
python run.py
```

Альтернативный способ:

```powershell
python -m src.main
```

Если приложение запускается без ошибок, откроется главное окно CryptoSafe Manager.

---

## 3. Создание мастер-пароля и хранилища

При первом запуске приложение предлагает создать мастер-пароль.

Мастер-пароль используется для получения криптографических ключей. Сам пароль не должен храниться в открытом виде.

Рекомендации к мастер-паролю:

* длина не менее 12 символов;
* наличие заглавных и строчных букв;
* наличие цифр;
* наличие специальных символов;
* пароль не должен повторять пароли от других сервисов.

После создания мастер-пароля приложение формирует защищённое хранилище и сохраняет необходимые служебные данные в локальную базу SQLite.

---

## 4. Вход в хранилище

При повторном запуске приложения необходимо ввести мастер-пароль.

Если пароль введён верно, хранилище разблокируется, и пользователь получает доступ к сохранённым записям.

Если пароль введён неверно, доступ к данным не предоставляется.

---

## 5. Добавление записи

Чтобы добавить новую запись:

1. Нажать кнопку **«Добавить»**.
2. Заполнить поля:

   * название записи;
   * имя пользователя;
   * пароль;
   * URL;
   * заметки;
   * теги.
3. При необходимости использовать генератор паролей.
4. Нажать кнопку сохранения.

После сохранения запись шифруется и помещается в базу данных.

---

## 6. Редактирование записи

Чтобы изменить существующую запись:

1. Выбрать запись в таблице.
2. Нажать кнопку **«Изменить»**.
3. Внести нужные изменения.
4. Сохранить запись.

После редактирования данные снова шифруются перед сохранением.

---

## 7. Удаление записи

Чтобы удалить запись:

1. Выбрать одну или несколько записей.
2. Нажать кнопку **«Удалить»**.
3. Подтвердить действие.

В приложении может использоваться мягкое удаление, при котором запись помечается как удалённая, но физически не удаляется сразу из базы данных.

---

## 8. Поиск записей

В главном окне есть поле поиска.

Поиск может выполняться по:

* названию;
* имени пользователя;
* адресу сайта;
* заметкам;
* тегам.

Также поддерживается фильтрация по отдельным полям, если она предусмотрена в интерфейсе.

---

## 9. Генератор паролей

Генератор паролей позволяет создать надёжный пароль с выбранными параметрами.

Можно использовать:

* заглавные буквы;
* строчные буквы;
* цифры;
* специальные символы;
* исключение похожих символов.

Сгенерированный пароль можно использовать при создании или редактировании записи.

---

## 10. Защищённый буфер обмена

CryptoSafe Manager поддерживает безопасное копирование данных.

Через интерфейс можно скопировать:

* пароль;
* имя пользователя;
* данные записи.

Особенности защищённого буфера обмена:

* автоматическая очистка через заданное время;
* ручная очистка;
* предупреждение перед очисткой;
* очистка при panic mode;
* запрет копирования, если хранилище заблокировано.

Если системный буфер обмена недоступен, приложение может использовать внутренний защищённый режим копирования.

---

## 11. Импорт данных

Приложение поддерживает импорт данных из разных форматов.

Возможные варианты импорта:

* зашифрованный JSON;
* CSV;
* Bitwarden JSON;
* LastPass CSV.

Перед импортом выполняются проверки:

* определение формата;
* проверка целостности;
* проверка размера файла;
* обработка дубликатов;
* очистка потенциально опасных данных;
* режим предварительной проверки без записи в базу.

---

## 12. Экспорт данных

CryptoSafe Manager поддерживает экспорт записей.

Возможные варианты:

* экспорт всего хранилища;
* экспорт выбранных записей;
* экспорт без заметок;
* зашифрованный JSON;
* CSV для миграции.

Рекомендуется использовать зашифрованный экспорт, так как открытый CSV может содержать пароли в читаемом виде.

---

## 13. Обмен данными и QR/key exchange

В приложении предусмотрены функции безопасного обмена данными:

* sharing package;
* обмен через пароль;
* обмен через открытый ключ;
* QR/key exchange.

Эти функции позволяют передавать отдельные записи без раскрытия всего хранилища.

---

## 14. Журнал аудита

Журнал аудита фиксирует важные события безопасности:

* вход в хранилище;
* неудачные попытки входа;
* создание, изменение и удаление записей;
* операции с буфером обмена;
* импорт и экспорт;
* panic mode;
* события автоматической блокировки.

Журнал используется для контроля действий и обнаружения подозрительной активности.

---

## 15. Автоматическая блокировка

Приложение может автоматически блокировать хранилище при неактивности пользователя.

Отслеживаются:

* действия мыши;
* ввод с клавиатуры;
* изменение фокуса окна;
* события блокировки экрана, если они поддерживаются платформой.

После блокировки для восстановления работы требуется повторная проверка мастер-пароля.

---

## 16. Panic mode

Panic mode предназначен для экстренной защиты данных.

Активация panic mode:

```text
Ctrl+Shift+Esc
```

При активации panic mode приложение может:

* заблокировать хранилище;
* очистить буфер обмена;
* очистить чувствительные данные из памяти;
* закрыть чувствительные окна;
* сохранить состояние сессии для последующего восстановления;
* записать событие в журнал аудита.

Восстановление после panic mode возможно только после повторной проверки мастер-пароля.

---

## 17. Security profiles

В приложении предусмотрены профили безопасности:

* **Standard** — стандартный режим;
* **Enhanced** — усиленный режим;
* **Paranoid** — максимально строгий режим.

Профили могут изменять:

* время автоматической блокировки;
* настройки буфера обмена;
* поведение tray/background режима;
* дополнительные меры безопасности.

---

## 18. Tray/background режим

Приложение может работать в режиме tray/background.

Поддерживаются:

* отображение состояния locked/unlocked;
* быстрые действия через меню;
* очистка буфера обмена;
* запуск panic mode;
* восстановление окна;
* уведомления о событиях безопасности.

---

## 19. Обработка ошибок

Приложение должно показывать понятные сообщения об ошибках.

Примеры ситуаций:

* неверный мастер-пароль;
* недоступность буфера обмена;
* повреждённый импортируемый файл;
* неподдерживаемый формат;
* заблокированное хранилище;
* ошибка при экспорте.

Вместо необработанных stack trace пользователь должен получать понятное сообщение и возможный способ решения проблемы.

---

## 20. Известные ограничения

Известные ограничения проекта:

* аппаратная защита от электромагнитного анализа зависит от среды выполнения;
* Windows Hello, macOS Keychain и Linux keyring рассматриваются как platform-dependent возможности;
* поведение system tray может отличаться на разных операционных системах;
* Python не позволяет полностью контролировать все копии данных в памяти;
* некоторые низкоуровневые меры безопасности реализованы как программные приближения.
